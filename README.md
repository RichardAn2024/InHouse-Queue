# 🏆 Inhouse Queue - Sistema de Partidas Customizadas para League of Legends

Um sistema completo para organizar partidas personalizadas (inhouses) de League of Legends, com integração automática ao cliente do jogo e à API da Riot Games.

## ✨ Funcionalidades

- 🎮 **Importação Automática** - Importa jogadores diretamente do seu saguão do LoL com um clique
- 🏅 **Ranks Reais** - Busca o elo verdadeiro de cada jogador na API da Riot
- ⚖️ **Balanceamento Inteligente** - Distribui os times baseado no MMR/ELO real dos jogadores
- 💬 **Integração com Discord** - Envia partidas formatadas para seu servidor via Webhook
- 📊 **Estatísticas** - Acompanhe histórico de partidas e estatísticas dos jogadores
- 🎯 **Flexível** - Funciona com qualquer número de jogadores (mínimo 2)
- 🔄 **Interface Limpa** - Design intuitivo inspirado no cliente do LoL

## 🖥️ Tecnologias Utilizadas

### Backend
- **Node.js** - Runtime JavaScript
- **Express** - Framework web
- **Axios** - Requisições HTTP
- **LCU API** - Integração com cliente do LoL
- **Riot Games API** - Busca de ranks

### Frontend
- **HTML5** - Estrutura
- **CSS3** - Estilização (Dark Mode)
- **JavaScript (ES6+)** - Lógica e interatividade

## 📋 Pré-requisitos

- [Node.js](https://nodejs.org/) (v14 ou superior)
- [League of Legends](https://www.leagueoflegends.com/) instalado e atualizado
- Conta de desenvolvedor na [Riot Games Developer Portal](https://developer.riotgames.com/)
